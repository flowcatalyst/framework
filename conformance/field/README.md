# Field-worker vectors

`jwks.json` and `cases.json` are copied unchanged from the platform repository
(`flowcatalyst-go`, `api/field-fixtures/`, generated by `tools/field-fixtures`) at platform commit
`b8c04573` ("field fixtures: access tokens RS256 (platform signer), proofs ES256; SDK verifier pins
RS256"). Do not edit them; copy new ones when the platform regenerates them and change the commit
here.

Contract: `docs/contracts/sessions-and-login.md` section 15.9. Each case gives `accessToken`,
`dpopProof`, `method`, `url`, `now` and `expect` (`valid` or a refusal reason). Go (`go/auth`,
`TestFieldConformance`) and Java run every case with three differences from a live request, all
for the vectors' sake:

- the application-nonce check is off (the vectors carry no nonce of the application's);
- the proof window is 5 minutes, not the contract's 24 hours (the `stale_proof` vector is a proof
  one hour old);
- the `expect` value `invalid_token` stands for any refusal of the parse, header, key and signature
  rules of section 5.5 (`malformed`, `alg`, `crit`, `kid`, `unknown_kid`, `signature`).
