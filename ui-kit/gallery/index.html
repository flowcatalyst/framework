Flash stack

c · server action

Server action (c): event: datastar-patch-elements / data: selector #flash-stack / data: mode append / data: elements <div class="fc-flash fc-flash-success" …>. Fallback: the stack listens to datastar-fetch; a non-2xx answer the server did not turn into a patch (403: refused; other 4xx/5xx: failed) or a network failure (offline) appends one generic banner from its <template>s. 401 is left to the application (the platform navigates to its login page). The two buttons trigger the fallback.

Dialog opened by the server

c · server action

Server action (c), shown at rest: @get('/users/42/reset-password-dialog'). Reply patches <dialog id="dlg-reset" data-init="el.showModal()" …> into body (mode append); data-init opens it as a modal as soon as it is in the DOM.
